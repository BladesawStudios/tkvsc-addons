# Addon Release 5

These add-ons need TKVSC 1.0.0. TKVSC moved to a new publisher, so uninstall the old add-ons and the old TKVSC (`TKVSC-Team.totk-vscode`), then install the new ones.

## TKVSC Ocarina of Time
v1.0.0
### Features
- New add-on. Browse and edit Ocarina of Time on Switch 2 through TKVSC
- Message tags show by name, and many flag hashes and AAMP keys show their names

### Known limits
- Edited files have not been tested in-game. Keep backups, and please report what you find
- About a third of the flag and save-variable hashes, and 89 AAMP keys, still show as numbers
